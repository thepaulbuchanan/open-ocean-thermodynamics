# Open Ocean Thermodynamics Project

An independent, data-first inverse modeling project evaluating the thermodynamic 
contributions of top-down (atmospheric) vs. bottom-up (geothermal/oceanic) energy fluxes.

## ⚖️ Epistemic Foundations

This project rejects the paradigm of forward-modeled climate predictions programmed 
with predefined atmospheric conclusions. Instead, we adhere to the classical scientific 
method via an inverse-engineering approach:

1. **The Phenomenology:** We rely strictly on verified observation networks (Argo, GRACE, NOAA) 
   to monitor the changing energy states of the oceans.
2. **The Ontology:** We treat the global ocean as the primary thermal flywheel of the planet, 
   insulated by the thermocline and bounded by a volatile crust below and gas above.
3. **The Epistemology:** We explicitly define the limits of what can be known, separating 
   measured physical states from statistical attributions.

## 🛠️ Methodology: The Staging Protocol
We divide the ocean vertically into three regimes (Surface Mixed, Permanent Thermocline, 
and Abyssal Plain). The framework utilizes a "chunked" data testing protocol, using 
prior historical years to forecast subsequent years, testing for model falsification 
without future-data bias.
